Census of India 2011 - Houselisting & Housing Census (HLO) - district-level household amenities & assets
=======================================================================================================
Fetched: 2026-09-29, plain public HTTPS GET requests only (no login, no cookies sent, no API keys).

PUBLISHER / SOURCE (official)
  Office of the Registrar General & Census Commissioner, India (ORGI), Ministry of Home Affairs, GoI.
  ORGI Digital Library (NADA catalogue): https://censusindia.gov.in/nada/index.php/catalog
  Series "Houselisting and Housing Census data", tag Census-2011. Per-file catalog + download URLs,
  byte sizes and sha256 hashes are in SOURCES.csv (231 files, all saved unmodified under raw/).

  Legacy paths tried and dead on 2026-09-29: https://censusindia.gov.in/2011census/hlo/HLO_Tables.html (404),
  .../hlo/hlo_highlights.html (404), http://www.censusindia.gov.in/... (connection refused).

TABLES USED (NADA idno -> raw file stem; 1 India file + 35 State/UT files each; state files carry
State, District, Sub-district and Town rows; universe = households excluding institutional households)
  HL-01  PC11_HL01-SS  DDW-HH0101-SS00.xls  households by condition of census house
  HL-06  PC11_HL06-SS  DDW-HH2206-SS00.xls  main source of drinking water x location (within/near/away)
  HL-07  PC11_HL07-SS  DDW-HH2507-SS00.xls  main source of lighting
  HL-08  PC11_HL08-SS  DDW-HH2808-SS00.xls  type of latrine facility (incl. open defecation)
  HL-10  PC11_HL10-SS  DDW-HH3410-SS00.xls  separate kitchen x type of fuel used for cooking
  HL-12  PC11_HL12-SS  DDW-HH4012-SS00.xls  households availing banking services + specified assets
  (The "HH-n" number printed inside each 2011 sheet = NADA "HL-n". In the 2011 release lighting is
   HH-7, cooking fuel HH-10, banking & assets HH-12, the % summary HH-14; the HH-12/HH-14/HH-17/HH-18
   numbers in the original brief do not match the 2011 numbering.)
  HL-14  PC11_HL14-SS-DDD  raw/hl14_sample/HLPCA-SSDDD-2011_H14_census.xlsx  (15-district sample only)
         "Percentage of households to total households by amenities and assets" - an independent ORGI
         product, 1 file per district (640 exist), rows down to VILLAGE/TOWN/WARD level, percentages
         only (1 decimal, no counts). Used here only to cross-check. Relevant for the later AC-level build:
         URL pattern https://censusindia.gov.in/nada/index.php/catalog/{id}/related-materials, ids for
         all 640 districts discoverable via
         https://censusindia.gov.in/nada/index.php/api/catalog/search?sk=%22amenities%20and%20assets%22&ps=2000
         (~0.05-1 MB each, est. ~250 MB for all 640).

DERIVED FILES (built by build_hlo_district.py from raw/ only)
  hlo_district_2011.csv        640 districts x Total/Rural/Urban = 1920 rows; % of households (2 dp)
  hlo_district_2011_counts.csv same keys; household counts (numerators) - use these for weighted
                               aggregation (district -> AC/PC), never average the percentages
  hlo_state_india_2011.csv     India + 35 States/UTs x T/R/U, same % columns
  hlo_validation.csv           all checks (all pass)
  Denominator = total_households = households excluding institutional households (HL tables; India
  246,740,228). This is NOT the PCA "No_HH" figure (which differs), so do not mix denominators.
  Column definitions: tap_water = tap from treated + un-treated source; telephone_any = landline only +
  mobile only + both; mobile_any = mobile only + both; computer_laptop = with + without internet;
  two_wheeler = scooter/motorcycle/moped; car_jeep_van as published; none_of_assets = none of radio,
  TV, computer/laptop, telephone/mobile, bicycle, two-wheeler, car; open_defecation = no latrine in
  premises and alternative source "Open"; house_good / house_dilapidated = condition of the census
  house (all uses) occupied by the household.
  12 rows have 0 households (no urban area: Lahul & Spiti, Kinnaur, Nicobars; no rural area: New Delhi,
  Central Delhi, Kolkata, Mumbai, Mumbai Suburban, Hyderabad, Chennai, Yanam, Mahe) - their % cells are empty.
