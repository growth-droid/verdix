- **`src/lib/signals.ts`** — pure detectors. `detectSignals(ctx: SignalCtx)` runs 7 pattern checks → `Signal[]` sorted by a severity-weighted score. `Signal = {id, severity:'critical'|'watch'|'note', party, a, headline (with the numbers), soWhat (the decision), metric, metricSub?, seats:Seat[], score}`; `SignalCtx = {seats (active scope snapshot), allRows (scope, all years), partyRows, vy, isState, arena}`. Imports `seatHistories` (analysis) + `linearTrend` (projections); never emits "pp" ([[verdix-no-pp]]).

THEME SWITCHING (how it works — don't fight it):
- `slate-*` and `white` Tailwind classes are backed by CSS vars (`--s50..--s950`, `--white`) defined for `:root` (dark) and `[data-theme=light]` in index.css, via `rgb(var(--sX) / <alpha-value>)` in tailwind.config. So EVERY existing `text-slate-*`/`bg-slate-*`/`border-white/[x]` flips by theme with zero per-element edits. Light is a tuned mirror of the slate scale (small numbers = dark text, large = light surfaces), not a naive invert. Semantic aliases: `text-ink`/`text-muted`/`text-faint`.
- Surfaces (`.card`,`.glass`,`.skeleton`, body gradient, scrollbars, slider track, maplibre popups) are driven by semantic vars per theme.
- State: `useThemeStore`/`useTheme()` in store.ts; persisted to localStorage `verdix-theme`; `data-theme` set on <html> early in main.tsx (no flash) and on toggle. Toggle button (sun/moon) lives in the App header.
- Charts: ECharts axis/grid/tooltip colors come from `DARK_ECHARTS`/`LIGHT_ECHARTS` theme objects (theme.ts). Use the `Chart` wrapper from ui.tsx (NOT raw `<ReactECharts>`) — it reads `useTheme()` and passes a stable theme-object ref, so echarts-for-react disposes+reinits on switch. Option helpers (baseOpt/catAxis/valAxis) hold NO colors. For inline chart labels/gridlines the registered theme can't reach (Sankey/pie labels, custom splitLines), use `labelColor(mode)`/`faintLine(mode)` and add `mode` to that memo's deps.
- Map: `ChoroplethMap` has `MAP_PAL[dark|light]` (bg/noData/line/hover); a `useTheme()`-driven effect repaints bg/line/hover + re-runs paint() on switch.
- COLOURS (round 8, dual-theme): `colors.ts` party/alliance palette is a SINGLE set tuned to read on BOTH canvases — the old neon-light tones (yellow/lime/light-cyan/light-slate) were deepened to mid-tones (e.g. TDP #eab308, BJD #65a30d, IND #475569) that stay vivid on dark yet keep contrast on white. Where a colour genuinely must flip by theme it's done per-component: ChoroplethMap `MARGIN_BANDS_L/D` + `TURNOUT_BANDS_L/D` (light variants drop near-white tones), MapPage party-scoreboard `OUT` fill, Trajectory strike-rate track (`faintLine(mode)`). Rule of thumb: pick a dual-theme value in colors.ts when you can; only go theme-aware for greys/tracks/bands that can't satisfy both.
